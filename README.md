# Çağ Trio Apartmanı C Blok Yönetim Sistemi

Bu paket, apartman sakinleriniz ve yönetici için hazırlanan web tabanlı yönetim ve bilgilendirme sistemidir.

## Vercel / Netlify Üzerinde Ücretsiz Yayınlama Adımları

1. Bu projeyi bir **GitHub** deposuna (repository) yükleyin.
2. [Vercel](https://vercel.com) veya [Netlify](https://netlify.com) sitesine ücretsiz üye olun.
3. **"New Project"** diyerek GitHub deponuzu seçin.
4. Ayarları değiştirmeden **Deploy** butonuna basın.
5. Birkaç saniye içinde size özel kalıcı bir web linki (`cagtrio-cblok.vercel.app` gibi) verilecektir. Bu linki tüm apartman sakinleriyle paylaşabilirsiniz!
